# Cosmetic Wings v4 — 1.21.4

Главный фикс этой версии — координаты косметики.
FeatureRenderer получает матрицу от основания игрока, поэтому старый код ставил крылья слишком низко. Теперь:
- ANGEL закреплён у лопаток (~1.1–1.3 блока от ног);
- 4 секции ангельских крыльев образуют пышный веер;
- отдельные 3D-пёрышки перекрываются слоями;
- DEMON закреплён у спины и имеет 2 массивных крыла;
- нимб находится над головой и сделан золотым;
- рога находятся по бокам головы;
- размер/анимация/настройки сохранены из предыдущей версии.
